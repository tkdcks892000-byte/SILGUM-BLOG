같은 검색어를 Google에서도 보고, Naver에서도 보고, Bing에서도 보고 싶을 때가 있습니다. 실검은 검색어를 다시 입력하지 않고 **서비스만 바꿔서** 이어 볼 수 있게 만들었습니다.

![검색 서비스 선택 화면](/screens/service-menu-1920.webp)
*검색창 왼쪽의 서비스 이름을 누르면 여덟 개 검색 서비스가 나옵니다.*

## 검색 서비스 여덟 개

현재 실검에서 고를 수 있는 서비스는 다음과 같습니다.

- Google
- Naver
- Bing
- Daum
- Yahoo
- 나무위키
- ZUM
- Nate

검색창 왼쪽의 서비스 이름을 누르고 원하는 서비스를 고르면 됩니다. 선택한 서비스의 검색 결과 페이지가 새 탭에서 열립니다.

## 검색어는 한 번만

예를 들어 `손흥민`을 검색한다고 해 봅시다.

1. Google을 선택하고 `손흥민`을 검색합니다.
2. Google 결과가 새 탭에서 열립니다.
3. 실검으로 돌아와 Naver를 선택합니다.
4. 검색어는 그대로 남아 있으므로 **검색**만 누르면 됩니다.

검색어를 복사하거나 붙여넣을 필요가 없습니다.

## 느낌표 약어

검색어 앞이나 뒤에 느낌표 약어를 붙이면, 현재 선택한 서비스와 상관없이 그 서비스로 바로 검색합니다.

```text
!g  Google
!n  Naver
!b  Bing
!d  Daum
!y  Yahoo
!w  나무위키
!z  ZUM
!nt Nate
```

예를 들어 `!n 날씨`를 입력하면 Naver에서 날씨를 검색합니다.

## 검색 결과를 합치지는 않습니다

실검은 여러 검색 서비스의 결과를 한 화면에 섞어 보여주지 않습니다. 서비스마다 결과가 다르고, 어떤 서비스를 봤는지가 중요하기 때문에 **각 서비스의 결과 페이지를 그대로 여는** 방식입니다.

또한 실검은 외부 검색 서비스의 검색량을 알지 못하고 추정하지도 않습니다. 순위표의 숫자와 검색 서비스의 검색량은 별개입니다.
