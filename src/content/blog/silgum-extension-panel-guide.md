실검을 쓰다 보면 “검색 결과를 보면서 옆에서 다른 서비스로 바로 넘어갈 수 있으면 좋겠다”는 생각이 듭니다. 그때 쓰는 것이 **패널**입니다. 패널은 검색 결과 페이지 위에 작게 열리는 실검 화면입니다.

![검색 도구 안내](/screens/search-tools-1920.webp)
*검색 도구 페이지에서 북마클릿과 확장 프로그램 설치 방법을 안내합니다.*

## 패널로 할 수 있는 일

![실검 패널 미리보기](/screens/panel-430.webp)
*패널을 열면 검색창, 검색 서비스 버튼, 실시간 트렌드 목록이 한 화면에 나옵니다.*

- 현재 보고 있는 검색어를 그대로 이어서 다른 서비스로 검색
- Google·Naver·Bing·Daum·Yahoo·나무위키·ZUM·Nate 바로 선택
- 실시간 트렌드 목록을 보면서 검색어를 패널에 넣기
- 검색 결과 페이지를 떠나지 않고 필요한 검색만 빠르게 실행

패널에서 서비스를 누르면 `?ref=extension`으로 유입 경로가 기록됩니다. 패널을 여는 것만으로는 아무것도 기록되지 않고, 실제로 검색을 실행했을 때만 집계됩니다.

## 두 가지 설치 방법

### 1. 북마클릿

가장 가볍게 쓸 수 있는 방법입니다. 검색 도구 페이지의 **SILGUM에서 검색** 버튼을 브라우저 북마크바로 끌어다 놓으면 됩니다.

검색 결과 페이지에서 북마클릿을 누르면 오른쪽에 패널이 열립니다. 설치 프로그램이나 확장 권한이 필요 없습니다.

### 2. 확장 프로그램

검색 결과 페이지에서 자동으로 SILGUM 버튼을 보고 싶다면 확장 프로그램을 씁니다.

1. [검색 도구 안내](https://silgum.co.kr/tools?ref=blog)에서 `silgum-extension.zip`을 내려받습니다.
2. Chrome은 `chrome://extensions`, Edge는 `edge://extensions`를 엽니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 내려받은 폴더를 고릅니다.
5. Google·Naver·Bing·Daum·Yahoo·ZUM·나무위키 검색 결과에서 SILGUM 버튼을 누릅니다.

확장 프로그램은 검색 결과 페이지에 버튼과 패널을 붙이는 역할만 합니다. 페이지 내용을 바꾸거나 검색 결과를 수집하지 않고, 저장 권한도 설정값을 보관하는 데만 씁니다.

## 어떤 방법을 고를까

- 가끔 쓴다 → **북마클릿**
- 검색 결과를 자주 본다 → **확장 프로그램**
- 회사 PC라 확장 설치가 어렵다 → **북마클릿**

설치는 [검색 도구 안내](https://silgum.co.kr/tools?ref=blog)에서 바로 할 수 있습니다. 검색 서비스 자체를 바꿔 쓰는 방법은 [검색 서비스 안내](https://silgum.co.kr/blog/silgum-search-services-guide/?ref=blog)에 정리해 두었습니다.
